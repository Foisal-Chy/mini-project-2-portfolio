# MP2: Responsive Website Development

**Course:** Software Development I (CSE-2340)
**Assessment:** Mini Project 2 (MP2)
**Student:** Md. Foisal Hossen Chowdhury
**Live Site:**

A simple, responsive personal portfolio website built with HTML and Tailwind CSS.

## Sections
- Navigation bar (About, Skills, Projects, Contact)
- About, Skills, Projects and Contact sections
- Footer

## Requirements Covered
1. **Navigation bar and content sections:** sticky navbar with four content sections.
2. **Tailwind CSS styling:** colors, spacing and typography are all done with Tailwind utility classes.
3. **Responsive layout:** the mobile menu collapses on small screens, and the Skills and Projects grids change columns with screen size.
4. **Interactive elements:** mobile menu button (CSS-only, no JavaScript), nav link hover, card hover effect, button hover and form input focus.

## Technologies Used
- HTML5
- Tailwind CSS (via CDN)
